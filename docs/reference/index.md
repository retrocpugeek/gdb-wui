# Reference

Tables to look things up in, rather than prose to read.

For the wire protocol between the browser and the server, and for how the
decompiler's address mapping works, see the developer documents in the
repository: [protocol.md](https://github.com/retrocpugeek/gdb-wui/blob/master/docs/protocol.md)
and [decompilation.md](https://github.com/retrocpugeek/gdb-wui/blob/master/docs/decompilation.md).
Those describe internals rather than use, which is why they are not part of this
site.
